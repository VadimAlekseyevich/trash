# Лабораторные №2–6 — Selenium WebDriver + LiteCart

Это отдельная серия методичек (файлы №2–6), использующая магазин **LiteCart**. Не смешивать с файлом «№1.docx», где внутри написано «Лабораторная работа №2» по **JUnit 4**.

## Задания

### №2 — Инфраструктура Selenium WebDriver
1. Подключить Selenium и тестовый фреймворк в Java-проекте.
2. Настроить **Chrome** и **Firefox**.
3. Выполнить первый тест в каждом браузере: открыть тестовый магазин, выбрать **Purple Duck**, проверить страницу товара.

### №3 — Базовые XPath
- Найти XPath **всех выделенных на рисунке 2 элементов** главной страницы LiteCart, убедиться в корректности каждого локатора.
- Критерии: поиск должен быть устойчивым к перемещению товаров, где возможно.

### №4 — Дополнительные XPath
1. Найти XPath выделенных на рисунке элементов с помощью перечисленных в методичке осей.
2. Подсчитать количество товаров **Most Popular** и найти последний.
3. Подсчитать количество товаров **Latest Products** и найти последний.
4. Найти элементы **Most Popular** через `contains`.
5. Определить позицию **Purple Duck** среди популярных.
6. Рассчитать суммарное количество в двух категориях.
7. Получить срок доставки для **Purple Duck**.

### №5 — Работа с элементами страниц
Проверить весь жизненный цикл администраторской учётной записи: создать `user`, активировать, войти, выйти, войти как `admin`, отключить `user`, удалить. Включить негативные сценарии.

### №6 — Поиск нескольких элементов
1. **Users**: подсчитать всех и активных пользователей; проверить «выбрать все».
2. **Translations → Search Translations**: подсчитать чек-боксы на всех страницах и проверить «выбрать все».
3. **Countries**: добавить области выбранной страны и проверить количество.
4. **Pages**: заполнить `Head Title` и `Meta Description` для каждой записи.

## Что необходимо для полного выполнения

- **Выбор нужных четырёх работ**: на руках шесть методичек, из которых пять относятся к Selenium.
- **Рабочий LiteCart** с URL магазина и админ-панели или разрешение развернуть собственный тестовый стенд. В документах пример: `http://localhost/litecart/` — это адрес *локальной* установки, а не доступный из интернета магазин.
- **Доступ к админке тестового стенда** для №5 и №6; креденшелы получать из переменных окружения, не коммитить в репозиторий.
- **Версия LiteCart и тестовые данные**: в методичках показаны Purple Duck, категории Most Popular / Latest Products, меню Users / Translations / Countries / Pages. Эти товары, разделы и локаторы следует проверять на конкретной версии и данных.
- **Критерии сдачи**: нужен ли отдельный отчёт со скриншотами/таблицей XPath, или достаточно Maven-проекта, результатов тестов и README.

## Предлагаемая реализация

Отдельный Java/Maven-модуль с Selenium и JUnit Jupiter, конфигурацией `BASE_URL`, `ADMIN_URL`, `ADMIN_USER`, `ADMIN_PASSWORD`, браузерами Chrome/Firefox, ожиданиями WebDriverWait и воспроизводимыми тестовыми данными. Код по №5–6 — только в собственной/разрешённой тестовой установке: тесты создают и удаляют пользователей и изменяют данные.

**Совместимость:** пример методички №2 ссылается на Selenium `3.14.0` и JUnit Jupiter. Для нового проекта лучше адаптировать API к Selenium 4; начиная с Selenium 4.6, встроенный Selenium Manager автоматически подбирает драйверы браузеров. Документация: https://www.selenium.dev/documentation/selenium_manager/

**Самостоятельная установка магазина:** https://www.litecart.net/en/download ; репозиторий https://github.com/litecart/litecart. На момент подготовки плана официальная версия LiteCart **2.7.2**; интерфейс может отличаться от старых скриншотов методичек.
