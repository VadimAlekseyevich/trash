# Тестирование программного обеспечения

Лабораторные работы по предмету (план: 4 работы).

> Название предмета предварительное: оно выбрано по теме присланной методички. При необходимости папку можно переименовать.

## Структура

- `lab_01/` — ожидаются методичка, программа и тестовые данные лабораторной №1.
- [`lab_02_junit/`](lab_02_junit/) — «Использование JUnit для тестирования классов» (методичка получена).
- `lab_03/` — задание пока не предоставлено.
- `lab_04/` — задание пока не предоставлено.

## Важное для лабораторной №2

В методичке требуется использовать результаты предыдущей лабораторной работы: тестовые данные из №1 и тестируемые классы/методы. Примеры с `ScholarshipCalculatorImpl` в документе служат иллюстрациями JUnit 4 и не заменяют индивидуальное задание.

Планируемая среда: Java + JUnit 4, инструмент сборки (Maven/Gradle) уточняется после получения проекта №1.
