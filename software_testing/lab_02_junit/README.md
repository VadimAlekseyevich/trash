# Лабораторная работа №2 — JUnit 4

**Тема:** «Использование JUnit для тестирования классов».

## Что требуется по методичке

1. Создать и отдельно выполнить тесты по данным, подготовленным в лабораторной №1, используя показанные в документе аннотации JUnit 4.
2. Построить параметризованные тесты на основе независимых тестов пункта 1.
3. Документировать результаты выполнения через обработку событий JUnit (`RunListener`).
4. Подготовить ответы на контрольные вопросы.

## Для полноценного выполнения нужны

- Задание/методичка лабораторной №1.
- Код, который тестировали/разрабатывали в №1, или исходное приложение для тестирования.
- Набор тест-кейсов, входных данных и ожидаемых результатов из №1.
- Если есть — вариант задания, специальные требования преподавателя к проекту и отчёту.

Документ, присланный под именем «ЛАБОРАТОРНАЯ РАБОТА№1.docx», внутри содержит заголовок **«Лабораторная работа №2»**.

## План реализации

После получения материалов №1: подготовить Java-проект (предпочтительно Maven), реализовать независимые и параметризованные тесты, фикстуры, проверки исключений, набор тестов и обработчик событий; запустить тесты и сохранить проверяемые результаты и краткий отчёт.
