# Лабораторная работа № 3 — дерево решений

**Дисциплина:** Проектирование интеллектуальных информационных систем.  
**Задание:** по методическим указаниям В. А. Саблиной «Обучение с учителем: дерево решений» (2026).

Самостоятельная реализация дерева классификации на данных пингвинов Палмера (`penguins.csv`). **Готовые классификаторы (`sklearn`, `DecisionTreeClassifier` и т. п.) не применяются.** Matplotlib/NumPy используются только для визуализации.

## Запуск

Требуется Python 3.10+; команды выполняются из этой папки.

```bash
python -m pip install -r requirements.txt
python main.py --variant 1
```

Номер варианта пока неизвестен, поэтому **по умолчанию выбран вариант 1** (длина и высота клюва). Любой вариант таблицы 1 можно запустить через `--variant 1` ... `--variant 11`, например:

```bash
python main.py --variant 11
python main.py --variant 7 --output-dir my_results
python main.py --variant 2 --no-plots
```

Для проверки алгоритма:

```bash
python -m unittest discover -s tests -v
```

## Алгоритм

1. Выбираются 2–4 количественных признака согласно варианту; строки с `NA` в используемых признаках исключаются (344 исходные записи, 342 пригодные).
2. Для каждого узла считается индекс Джини: `G = 1 - Σ(p_i²)`.
3. Для каждого доступного признака рассматриваются середины между соседними уникальными значениями. Выбирается минимум взвешенного Джини `n_L/n * G(L) + n_R/n * G(R)`.
4. Рассчитывается выигрыш `ΔG = G(parent) - G_weighted`. Рекурсивное разделение продолжается для **оставшихся** признаков (вдоль пути признак не используется повторно).
5. Узел становится листом, если доля преобладающего вида ≥ 0,9, нет доступных признаков или невозможно улучшить Джини. Класс листа — наиболее частый вид (при равенстве — фиксированный порядок видов).
6. На том же наборе вычисляется доля верных предсказаний **отдельно для Adelie, Gentoo и Chinstrap**.

## Результаты (`output/`)

| Файл | Содержимое |
| --- | --- |
| `decision_tree.png` | Дерево со значениями признаков, порогами, Джини и выигрышем |
| `decision_regions.png` | Области классов по первым двум признакам |
| `predictions.csv` | Истинный вид, предсказанный вид и признак ошибки каждой строки |
| `metrics.json` | Общая точность, процент верных ответов по видам и матрица ошибок |

**Важно:** для вариантов 7–11 диаграмма областей — двумерный срез: остальные признаки зафиксированы на медианах; реальные точки нанесены с исходными значениями. Это **не** визуализация всей 3D/4D границы. Оценка точности проводится **на обучающей выборке**, как требует методичка; её нельзя трактовать как точность на новых данных.
